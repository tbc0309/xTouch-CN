ESP32 · 蓝牙像素屏联动

让拓竹打印状态，亮在身边。

为 ESP32 开发板安装固件，通过蓝牙将打印状态显示在 iDotMatrix 32×32 像素屏上。带 OLED 的 ESP32-C3 也可在板载屏查看状态。

一款运行于 ESP32 的独立像素屏控制器。

———
USB 在线安装

连接并刷写

  1. 电脑使用 Chrome 或 Edge，通过 USB 连接开发板。
  2. 关闭占用串口的软件，确认主板型号后加载刷写工具。
  3. 选择开发板串口，按提示完成安装。

保留设置时不要勾选 Erase device；擦除会清除 Wi-Fi、打印机、像素屏绑定和管理密码。安装过程请保持 USB 连接。

刷写工具的连接、进度和确认窗口由 ESP Web Tools 提供，目前为英文。

Wi-Fi 与像素屏

首次使用

  1. 连接开发板的 PrintPixel-xxxxxx 热点，密码 12345678。
  2. 打开 http://192.168.4.1/，直接扫描并设置 Wi-Fi，无需登录。
  3. 连接同一网络，在设备地址首次登录（初始密码 12345678），按提示修改密码，再添加打印机。
  4. 断开手机 App 与像素屏的连接，扫描选择像素屏，按需填写设备密码，启用联动。

开发板和像素屏分别供电，无需连接信号线。

BOOT 长按 3 秒清除 Wi-Fi，长按 10 秒清除全部配置。
