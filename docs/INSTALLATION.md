# 安装、升级与账号

简体中文 | [English](INSTALLATION.en.md) | [文档目录](README.md)
通过在线安装器或 GitHub Releases 获取固件。核对版本、完整主板型号及该版本的功能清单；网页升级使用应用镜像，USB 安装使用完整镜像。

<a id="install"></a>
## 安装与升级

| 主板 | 应用镜像（后台／OTA／SD 更新） | 完整镜像（USB 安装） |
|---|---|---|
| ESP32-2432S028R | `xtouch-2.8.bin` | `xtouch-2.8-full.bin` |
| ESP32-S3-Touch-LCD-2.8 V2 | `esp32-s3-touch-lcd-2.8-v2.bin` | `esp32-s3-touch-lcd-2.8-v2-full.bin` |
| ESP32-P4-WIFI6-Touch-LCD-4.3 | `esp32-p4-wifi6-touch-lcd-4.3.bin` | `esp32-p4-wifi6-touch-lcd-4.3-full.bin` |
| LCDWIKI ES3C35P | `lcdwiki-es3c35p.bin` | `lcdwiki-es3c35p-full.bin` |

先确认完整主板型号、触摸版本与芯片修订。各主板镜像不能混刷；不要把完整镜像上传到后台、OTA 或命名为 SD 的 `firmware.bin`。

### 首次 USB 安装

1. 用电脑 Chrome／Edge 打开[在线安装页](https://tbc0309.github.io/xTouch-CN/)，选择正确主板及数据串口。
2. 按提示安装。需要保留内部设置时不要勾选 Erase device；仍应先导出备份。
3. 无法自动进入下载模式时，按住 BOOT，点按 RESET 后松开 BOOT，再连接安装。
4. CYD 首次启动完成触摸校准，S3／P4／ES3C35P 无需 CYD 校准。

网页安装按分段保留用户数据区；将完整镜像手动从 `0x0` 写入可能覆盖 NVS 和设备凭据密钥。整片擦除或重置后，旧备份中的设备绑定密文可能无法解密。需要全新配置时移除 SD 卡，避免旧配置自动导入。

### 更新已有设备

从 **1.0.0 的 S3／P4** 升级到 1.0.1，请通过网页管理上传对应应用 `.bin`，或使用 USB 安装。1.0.0 的在线下载大小上限无法接收新版镜像；1.0.1 已改用各主板的应用分区上限。

- **后台**：维护页上传同一主板的应用镜像，确认后等待重启。
- **在线 OTA**：设置页可启用开机检查；版本栏连续三击可手动检查更高版本。清单检查最长 15 秒，确认新版后的固件下载另计。
- **SD**：关机，将应用镜像放到卡根目录并命名为 `firmware.bin`，清除旧 `xtouch/ota.json` 和残留 `.part` 后开机。

在线更新通过 HTTPS 获取本项目对应主板清单和应用镜像，检查长度与 MD5 后写入备用应用槽。MD5 检测传输损坏，不等于发行者签名。保持供电，不在保存或升级时拔卡。失败时通常保留原应用；不能启动则使用 USB 重新安装。

<a id="accounts"></a>
## 配网与网页管理

1. 首次无网络配置时扫描屏幕二维码，连接热点（默认密码 `12345678`），打开 `http://192.168.4.1/` 配置家庭 2.4 GHz Wi-Fi。
2. 连入路由器后，从设置打开“网页管理”并扫码访问设备地址。
3. 用初始管理密码 `12345678` 登录，按提示修改。新登录会替换旧浏览器会话。
4. “添加局域网设备”填写型号、地址、访问码及序列号，验证成功后保存；云设备从对应账号关联列表勾选。

配网取得 IP 地址后才保存新网络，页面显示成功及设备地址，热点约 10 秒后关闭。密码错误或连接失败时保留原配置，可修改后重试；从设置退出扫码页会取消尚未完成的连接并恢复原网络。

已保存网络不可用时，每轮最多连接 3 次，约 30 秒后提供恢复配网入口。设置中打开的配网页闲置 3 分钟后关闭热点；首次尚未配置网络时保留配网入口。路由器改名或改密码后，可通过该入口重新设置，无需清空设备。

已保存的可编辑字段双击解锁，也可聚焦后按 F2／Enter。需验证的字段解锁后显示灰色按钮，有效变更后可点击；自动保存字段按页面提示保存。连接方式等来源信息只读。屏幕语言与后台语言分别保存，不互相覆盖。CYD 只有中文和英文；S3／P4／ES3C35P 提供八语。

### 拓竹账号登录

标准构建默认编入独立的 Token 和账号登录模块。选择区域后，可粘贴 Access Token 验证，或填写手机号／邮箱与密码，并按提示完成短信／邮箱验证码。登录成功后勾选关联设备。

临时网络失败不会删除账号。Token 失效时在原账号中重新验证，或按页面提示重新登录。清除本地登录不会撤销云端 Token。验证码需要用户参与，不能保证自动重新登录。账号和密码输入不替代打印机命令授权，见[权限说明](PRINTERS.md#authorization)。

### 可选蓝牙配网

普通构建使用 Wi-Fi 热点配网。S3 与 ES3C35P 可选择编译蓝牙配网，通过 ESP BLE Provisioning App 扫码，手动设备名前缀为 `PROV_`，校验码为 `abcd1234`。蓝牙配网与温湿度计接收是互斥的构建选项，见[构建限制](DEVELOPMENT.md#options)。

蓝牙配网每次会话最多接受 3 组失败的网络凭据，失败后可更正重试。成功、取消或 3 分钟超时后服务关闭；取消或失败不会覆盖原网络。Wi-Fi 热点与蓝牙配网分时使用，切换方式会先关闭上一种服务。

<a id="token"></a>
## 获取与导入 Access Token

1. 在电脑浏览器登录账号所属地区的[中国官网](https://bambulab.cn/)或[国际官网](https://bambulab.com/)。
2. 按 F12，在 Application／应用中打开 Storage → Cookies，选择当前网站域名。
3. 找到名为 `token` 的 Cookie，复制 Value。未找到时确认登录成功后刷新。
4. 在设备后台添加拓竹账号，选择相同地区，粘贴 Token 并验证，再勾选打印机。

只复制值，不复制整行；不向第三方网页提交 Token，也无需在控制台执行脚本。Token 相当于登录凭据。页面变化时以官网当前登录结果为准；参考 [补充图文教程](https://bambuhelper.stolaris.dev/cloud-token.html)。

## 温湿度计与备份

在温湿度计页绑定 MAC；明文广播可不填 BLE Key，加密广播需要正确密钥。显示模式、间隔、支持型号和小米密钥获取见[温湿度计](THERMOMETERS.md)。导入、导出与重置见[维护指南](MAINTENANCE.md)。

使用备用配置生成器时，先选择实际主板，再选择屏幕与后台语言。标准 CYD 固件只提供简体中文和英语；切换到 CYD 后，不支持的语言会改为英语。生成器不会上传配置，导出的文件包含明文凭据，需私下保管。

CYD 最多保存20台设备、10个账号。现有 CYD 配置超出上限时，升级前请先在当前固件中减少数量并导出备份；超限备份无法导入。
