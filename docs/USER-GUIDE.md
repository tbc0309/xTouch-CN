## 屏幕操作

| 位置 | 操作与反馈 |
|---|---|
| 首页设备卡 | 两台以内点按切换；三台及以上点按打开选择页；长按始终打开选择页 |
| 设备选择 | 绿色边框表示当前设备；CYD 仅列表，S3／P4／ES3C35P 可切换图片与列表 |
| 打印进度 | 准备阶段黄色，实际打印绿色；状态由打印机报告更新 |
| 温度／风扇 | 数字键盘选择参数、输入、绿色键确认；红色键删除，空输入时返回 |
| 运动 | 选择步距再移动；归位、挤出等需确认，忙碌时禁用 |
| 耗材 | 点选来源不会换料；确认进退料后才发送，长按 AMS 名称查看详情 |
| 设置版本号 | 三击检查更新，八击请求重置确认 |

设置及设备列表滑动停稳后再操作。超限数值不会发送；切换设备会清除原设备的选择和提示。设备来源颜色表示 LAN／Token／手机号／邮箱来源，不表示在线状态。

AMS 余量原色区域：耗材页右侧亮、左侧淡；首页下方亮、上方淡。未知余量显示纯色，不伪造百分比。AMS 名称固定，温度在湿度前显示。外置来源使用紧凑的固定按钮，可见 AMS 均分剩余标题区域，卡片间距一致；多出的 AMS 可横向浏览。无外置时单 AMS 占满标题。读数能放下时静态居中，超宽时使用剩余区域滚动；连完整温度都容不下时隐藏读数。重复上报相同内容不会重启滚动。

### 摄像头

打印机报告具备摄像头时显示图标。白色表示录像与延时摄影均未开启，绿色表示监控录像开启，延时摄影开启时绿色闪烁；可打开本地摄像头时，图标定位框右上角另加蓝点。设置状态与实际录像状态按协议分别处理。

支持的 JPEG 摄像头可打开全屏查看，底部提供灯光、暂停／播放和重新连接；顶部关闭返回原页面。蓝点只表示存在可访问入口，不保证打印机此刻可连接。协议范围见[摄像头说明](../boards/CAMERA.md)。

### 显示、声音与待机

默认亮度 200，音量 20%，联网待机时间 15 分钟；触摸音、警告音和自动深睡默认关闭。普通待机关闭屏幕、保留网络，可由打印状态或触摸唤醒。自动深睡启用后，默认等待 60 分钟并满足空闲条件才进入；深睡断网，唤醒后重新启动。ES3C35P深睡使用BOOT键，不能通过触摸唤醒；其余主板按对应板级说明操作。

S3电源键、P4／ES3C35P的BOOT短按可切换联网待机。RESET是复位，P4 POWER是硬件电源开关，不能混用。BOOT联网待机与深睡是两种状态：ES3C35P在联网待机时仍可触摸唤醒。

## 网页操作

已保存的可编辑字段双击或 F2／Enter 解锁；未改动时失焦回锁，待保存内容保持可编辑。验证／绑定按钮解锁后灰色显示，有有效修改才可点击；保存成功重新锁定。只读字段不可编辑。名称、备注及部分设置自动保存；连接凭据必须验证。

屏幕与后台分别保存语言。CYD 为中文／English，S3／P4／ES3C35P 为八语。后台刷新遵循设备保存语言，不由浏览器自动覆盖。

| 操作 | 结果 |
|---|---|
| 亮度、语言、音量、显示间隔 | 有效配置自动保存并应用 |
| LAN 参数、Token、温湿度计绑定 | 验证或绑定成功才保存，失败保留原配置 |
| Wi-Fi 修改 | 重连网络，地址可能变化 |
| 管理密码 | 修改后重新登录 |
| 固件更新、重置、翻转 | 按确认提示重启 |

## 提示与故障

信息为蓝色，警告为黄色，错误为红色。操作确认包含当前对象和参数，危险操作需要明确确认。确认超时、切换设备或状态失效后不执行；机械控制超时不会自动反复重发。

HMS 与打印错误保留原始代码。S3／P4／ES3C35P 显示英文文字详情；CYD 显示代码，可用[在线查询](https://tbc0309.github.io/xTouch-CN/errors.html)。弹窗随内容增高，到屏幕上限后正文可滚动；超长详情行独立滚动，标题和操作按钮保持可见。

- 关闭只关闭本地提示，不清除打印机故障。
- 重试、完成仅在当前故障支持时显示。
- 已确认且持续存在的同一故障不反复弹出，新故障仍会提示。
- 授权错误 `84033543` 或 HMS `0500-0500-0001-0007` 会增加黄色“部分控制功能需局域网模式及开发者模式”提示。见[权限说明](PRINTERS.md#authorization)。

网页登录失效时重新登录；云账号失效时更新对应账号。普通网络失败不会清除配置或账号。
