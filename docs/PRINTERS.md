# 打印机、AMS 与控制兼容

简体中文 | [English](PRINTERS.en.md) | [文档目录](README.md)

型号识别、状态解析和控制权限是不同能力。识别机型或显示图片，不代表其全部机械操作已经实测。以下功能依赖打印机有效上报、外设及固件权限；未知数据不补成零，不从其他设备借用。

<a id="capabilities"></a>
## 状态与操作

| 类别 | 范围 |
|---|---|
| 打印 | 进度、剩余时间、层数；支持时暂停、恢复、取消 |
| 温度／风扇 | 实际与目标温度、有效仓温、机型支持的风扇及速度档位 |
| 耗材 | AMS／外置来源、材料、颜色、有效余量、温湿度 |
| 手动控制 | 空闲时归位、步进移动、受限挤出／回抽、进退料和重读 |
| 错误 | HMS、打印错误及对应确认／重试／完成动作 |

命令发送成功仅表示请求已发出，不表示动作完成。确认实际状态更新；超时不自动重复发送机械命令。湿度等级和百分比不是同一量，余量只有打印机提供时才显示。

<a id="ams"></a>
## AMS 与喷头

耗材页点选来源为蓝框，实际装入为绿框。再次点同一槽取消选择；长按 AMS 名称查看详情。进料／退料／RFID 重读先核对确认框。外置来源不提供 AMS RFID 重读。

进料可能引发退料、加热及移动。打印、准备、暂停、AMS 忙碌或读取标签时，冲突控制禁用。多 AMS 可横向切换，外置入口独立显示。

### 双喷头与仓温

T0／T1、外置路径与热端仓按上报绑定关系显示；来源不明确时禁止相关操作。喷嘴输入为 0～300℃，0 关闭；挤出／回抽要求对应喷嘴至少 170℃。支持主动仓温的机型才显示加热入口，X1E 上限 60℃，其他已支持加热机型上限 65℃。P1S 不提供主动仓温加热。

H2C 热端仓按协议提供位置、类型、直径及部分维护入口，不提供完整自动热端交换。未适配的新风道、热床等不能仅凭新协议字段推断已可控制。

### 烘干

| 外设 | 温度 | 时长 |
|---|---|---|
| AMS 2 Pro | 45～65℃ | 1～24 小时 |
| AMS HT | 45～85℃ | 1～24 小时 |
| AMS／AMS Lite | 无烘干控制 | — |

修改参数后必须确认开始；忙碌时限制启动，烘干／检查／冷却期间可请求停止。旋转料盘、自动烘干、共享供料重分配等未提供。新型 AMS、双喷头和热端仓的适配依赖协议版本，不等于已覆盖所有固件组合。

<a id="authorization"></a>
## 连接与权限

局域网设备使用本机地址、序列号和访问码；云设备使用自己的账号、区域和序列号。账号 Token 不等于命令签名。当前不提供官方云签名控制通道，部分命令要求打印机开启局域网模式与开发者模式。

收到 `84033543` 或 `HMS 0500-0500-0001-0007` 时核对打印机权限及对应 LAN 配置；更新 Token 不能解除此限制。权限随打印机型号和固件变化，不将一次机型测试扩展为全部设备结论。关闭本地提示不会清除手机 App／打印机上的授权故障。

CYD 的内部内存有限，云账号校验期间会暂时释放 MQTT 连接供 HTTPS 使用，结束后重新连接。此时可能短暂显示离线；不代表打印任务停止。状态恢复后再操作控制，避免连续刷新账号。

## 摄像头与缩略图

摄像头协议独立于 MQTT 状态。S3／P4／ES3C35P 支持本地 JPEG 摄像头；RTSPS／H.264 有解码与内存限制，见[摄像头指南](../boards/CAMERA.md)。可访问本地摄像头允许按相同序列号关联本地连接资料，该例外不用于借用状态、温度、任务、错误或缩略图。

LAN 缩略图从当前任务文件按盘号获取；云缩略图来自同一账号、同一序列号、同一任务的 API。MQTT 盘号未知时可由该云响应确定；MQTT 明确盘号时严格匹配。不会默认将未知当成第 1 盘，也不会使用其他 LAN 设备的任务。缺图时 S3／P4／ES3C35P 显示机型图；CYD 打印时为绿色拓竹 Logo，待机保留 xTouch Logo。

<a id="models"></a>
## 型号识别

当前资源与解析包含 X1／X1 Carbon／X1E、P1P／P1S、A1／A1 mini、P2S、X2D、A2L、H2C／H2D／H2D Pro／H2S 等代码。型号来自上报及账号列表；未知时保留标志，不猜测控制能力。代码表以[机型资源清单](../resources/printer-images/source.json)和[型号解析](../src/ui/printer_models.h)为准。

纯云、局域网、新旧字段、AMS 版本和机械控制需要分别验证。公开功能描述不替代设备自身的安全和权限限制。
