## 保存在哪里

设备日常运行不需要 SD 卡。设置保存在内部存储；插卡后可同步配置备份。后台维护页可导出或导入网络、设备、账号和应用设置。

| 文件 | 内容 |
|---|---|
| `xtouch.json` | Wi-Fi、打印机、云账号与默认设备 |
| `xtouch/settings.json` | 语言、显示、时间、待机、声音及更新设置 |
| `xtouch/touch.json` | CYD 触摸校准，不可跨设备套用 |
| `xtouch/hardware.json` | 屏幕方向 |

温湿度计绑定由模块独立保存，并随后台配置备份中的 `environmentSensor` 导出。不要把实时读数、健康状态或验证码作为配置导入。

网页备份不包含管理密码、设备凭据密钥、CYD 触摸校准或独立硬件方向文件，不是整片 Flash 镜像。保留已有硬件设置使用普通应用更新；擦除后按主板流程重新校准或设置方向。

### 备份与恢复

1. 在维护页下载配置，保存到私人位置。
2. 恢复前核对主板与配置来源，在维护页导入并按提示确认。
3. 设备绑定密文恢复到另一块板、或设备密钥被重置后，需要重新输入对应凭据。

没有有效内部配置时可从 SD 导入。两边都有配置时按版本、修改时间和同步状态处理；无法判断时保护未备份的内部更改。无效 JSON 不覆盖有效内部文件。运行中检测到新的 SD 配置可能重启；仅回写备份不重启。

`*.previous` 保留上次有效文件；`*.conflict`／`*.invalid` 留存冲突或无效输入；`*.tmp`／`*.part` 是写入中的文件。核对当前配置和备份后再清理，不在保存或升级时断电拔卡。

### 手动 JSON

完整后台备份的根对象包含账号、设备及 `settings`；若单独写 SD 的 `xtouch/settings.json`，只写设置对象内容。JSON 为 UTF-8，布尔值不用引号。`activePrinter` 从 0 计数；云设备 `accountId` 必须引用存在的账号。

CYD 最多保存20台打印机、10个账号；其他主板最多100台打印机、50个账号。实际受可用内存及凭据长度限制，一次只连接一台。`_storage` 元数据和密文由固件维护，不要自行构造。手动替换明文 Token 时移除旧 `tokenEnc` 并将 `tokenEncrypted` 设为 `false`。

### 时间

`timezone` 使用 POSIX 规则，`timezoneName` 是说明名称。默认 NTP 为 `ntp.aliyun.com`；未配置时暂用北京时间。NTP 同步后显示时钟。浏览器时区同步默认开启，只在时区未配置时填入并保存，之后不随其他浏览器覆盖。

```json
{"timezone":"CST-8","timezoneName":"Asia/Shanghai","ntpServer":"ntp.aliyun.com","browserTimezoneSync":true}
```

修改时区和 NTP 不需重启。首页空间不足时隐藏时钟，并非同步失败。

## 重置与恢复安装

普通应用更新保留配置；整片擦除清除内部数据，SD 文件仍在。重置会清除管理密码并更换凭据密钥。需要全新状态时先移除 SD 卡；加密凭据恢复失败时重新输入。设备无法启动时使用[USB 安装](INSTALLATION.md#install)，不要套用其他主板的分区地址。

网页和 SD 应用更新同时核对芯片及固件项目标识。同芯片的不同屏幕主板也不能混刷；旧框架镜像可能被拒绝。需要切换主板固件或回退旧框架时，先备份，再使用对应主板的 USB 完整安装包。

<a id="security"></a>
## 安全边界

- 管理后台是可信局域网内的 HTTP 服务，不直接暴露到公网。初始密码 `12345678` 首次登录后须修改。
- 新登录替换旧会话；修改管理密码注销当前会话。退出后不能继续使用原会话。
- 访问码、Token、密码与 BLE Key 按页面选项保存。“加密并绑定”使用设备密钥，不能让备份在其他设备自动解密。
- Wi-Fi 密码与未选择加密的凭据为明文。配置备份不是脱敏文件；不要公开分享。
- 管理密码以带随机盐的 PBKDF2 哈希独立保存，不在普通配置备份内。
- 未启用硬件 Flash 加密，设备绑定加密不防止所有物理读取。
- 云 API、云 MQTT 与更新验证服务器证书；本地打印机兼容自签名证书。摘要检查不等于固件签名。
- 配置校验或保存失败保留原配置；未完成的凭据验证不覆盖已保存值。
