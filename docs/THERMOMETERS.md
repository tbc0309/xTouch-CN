# 蓝牙温湿度计

简体中文 | [English](THERMOMETERS.en.md) | [文档目录](README.md)

CYD、S3、P4 和 ES3C35P 标准固件默认包含本模块。每块控制屏绑定一只传感器，固件从广播产品 ID 识别型号，不需要手动选择。支持 MiBeacon 广播不等于支持米家 App 的全部商品。

<a id="binding"></a>
## 绑定

1. 在后台打开温湿度计，填写 MAC。
2. 明文广播可只填 MAC；加密广播填写 32 位十六进制 BLE Key，可选择“加密并绑定”。
3. 保存并绑定，等待温度与湿度广播。收到有效广播后显示“产品名称（型号标识）”。
4. 选择“关闭显示”“交替显示”或“仅温湿度”。默认交替，滑块 1～30 秒、默认 5 秒。

屏幕设置中的“温湿度计”卡片与语言选择使用相同布局，可修改同一份显示模式，修改后自动保存并与后台同步。未绑定传感器时下拉框灰色禁用；绑定后即可选择，不要求已收到读数，也不要求明文广播设备提供 BLE Key。删除绑定后下拉框自动禁用。

已保存 MAC 双击解锁后显示灰色保存按钮，有效修改后启用。更换 MAC 且留空密钥会清除旧设备密钥；相同 MAC 留空则保留原密钥。缺少加密广播所需密钥时提示填写，不借用其他传感器密钥。

<a id="ble-key"></a>

### 获取密钥

使用 [Xiaomi Cloud Tokens Extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor)：先在米家 App 完成设备绑定，再在电脑按项目说明运行 Release 程序或 Python，登录同一小米账号并选择地区，从设备列表读取 MAC 和 BLE KEY。只使用这两个字段，不使用云 TOKEN。

```yaml
NAME:     领普温湿度传感器
ID:       blt.3.example
BLE KEY:  00112233445566778899aabbccddeeff
MAC:      02:86:B2:90:CE:4B
IP:       192.0.2.48
TOKEN:    00000000000000000000000000000000
MODEL:    linp.sensor_ht.ks2bb
```

以上为虚构格式示例。设备绑定密钥恢复到另一控制屏或重置后可能需重新填写。

<a id="compatibility"></a>
## 协议边界

支持表内 ID 的 MiBeacon v2／v3 明文、v4／v5 AES-CCM 加密，以及 `0x1004`／`0x1006`／`0x100D`、`0x4801`／`0x4802`／`0x4808` 温湿度对象。不支持 v2／v3 旧加密格式、未知 ID、Zigbee、Wi-Fi、ATC、PVVX 或 BTHome。时钟类仅读取温湿度；不控制闹钟、校时或 CO₂ 等附加功能。


<a id="reporting"></a>
## 采集与显示

被动扫描每 100 ms 周期监听 30 ms，不主动连接或要求传感器测量。上报周期和变化阈值由传感器决定。温度保留一位小数，湿度统一舍去小数显示整数百分比。

温湿度可分开广播，各自记录上报时间；两项均有效才在首页显示。重启或换绑定清空缓存，重新等待广播。显示模式和间隔改变保留读数。任一值超过 10 分钟未更新时加 `~`，表示读数较旧，不等于确认故障。

首页每秒检查数据；交替间隔只控制 AMS 与温湿度展示，无 AMS 时直接显示温湿度。关闭显示仍接收。后台约每 5 秒更新上报时间。刷新或保存不会触发新测量；请保持在接收范围内并等待下一次广播。
