# SD 打印文件浏览

ESP32-S3／ESP32-P4 标准固件在主板具备 SD 适配时默认启用。插入可用 SD 卡，配置打印机的局域网连接后，点击首页机型图片进入文件页。云设备可使用已保存的同序列号局域网配置访问文件，状态连接保持云端；不支持纯远程文件访问。

## 浏览与重新打印

- 支持列表和图片模式，按文件修改时间由新到旧排列。先显示已有缓存，再逐张补充缩略图；滑动停稳后可选择文件。
- 读取根目录及其列出的 `/cache`、`/model`、`/data` 目录，不递归任意子目录。清单来自打印机存储，不是手机 App 的打印历史。
- 显示 `.gcode` 和 `.3mf`。已确认的切片包按具体打印盘列出；可靠关联的 G-code 副本合并到对应盘，无法关联的文件单独保留。
- 详情显示封面、盘号，以及可获取的预计时间和耗材克重。未确认含打印指令或盘号不明的归档仅供浏览，重新打印按钮不可用。
- 打印前复核文件、设备和在线状态；正在打印时不可再次提交。发送后显示打印机接受、拒绝或未确认的结果，等待期间禁止重复提交。控制权限由打印机决定，部分固件需要局域网与开发者模式。

## 缩略图与缓存

优先读取打印机的独立 PNG 缓存；缺少缓存时，在最多 1 MiB 的归档前缀中查找封面并关闭连接。G-code 通过最多 1024 字节头部及关联摘要核对来源。无法可靠关联或超出读取限制时显示占位图，不完整下载大文件。

缓存按打印机序列号保存在控制屏 SD 卡：

```text
/xtouch/gcode/<设备序列号>/index.jsonl
/xtouch/gcode/<设备序列号>/cache/<远端目录>/<原文件名>.png
/xtouch/gcode/<设备序列号>/cache/<远端目录>/<原文件名>.stamp
```

文件大小或修改标记变化时，旧关联和缩略图失效。完整刷新成功后清理已删除文件的缓存；网络失败时保留上次清单。缓存不占用内部配置分区，也不保存完整 G-code。

可见图片逐张读取，网络读取和元数据获取可随翻页或退出取消。图片列表的单图读取预算为 15 秒，详情重试为 30 秒；失败不会阻塞其他卡片，手动刷新可重试。目录上限为 2000 项，超限不会作为完整清单保存。

## 构建与源码

`python boards/build.py es3c35p --gcode-browser` 可显式启用，`--without gcode_browser` 可关闭。直接 CMake 构建使用 `XTOUCH_FEATURE_GCODE_BROWSER`。字体和资源选项见[开发指南](../../../docs/DEVELOPMENT.md#options)。

| 文件 | 职责 |
|---|---|
| `catalog.cpp` | FTPS 清单、文件关联、索引与缩略图缓存 |
| `view.cpp` | 文件列表、图片和详情界面 |
| `commands.cpp` | 打印前校验与请求提交 |
| `policy.h` / `print_request.h` | 输入限制和打印命令 |
| `features/network/ftps_session.h` | 共享 FTPS 连接与收尾 |

SD 挂载和文件句柄由共享存储层管理；LVGL 对象由主循环管理。退出页面、切换设备或移除 SD 卡时取消后台读取。
