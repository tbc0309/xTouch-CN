# 32 像素屏联动

ESP32-S3 / ESP32-P4 标准构建默认启用的可选模块，可通过 `--without pixel_screen` 关闭。使用 `python boards/build.py es3c35p --pixel-screen` 编译；使用 `--without xiaomi_ble` 可独立关闭温湿度计。像素屏与蓝牙配网不能同时启用。CYD 的标准容量配置不包含像素屏模块。

- 后台扫描选择目标，保存设置后开启联动；不自动连接未配置的附近设备。
- `connection.cpp` 管理连接、认证、设备能力、传输队列及取消；`link_protocol.cpp` 编解码协议；`display_policy.cpp` 决定内置时钟和上传画面；`core.cpp` 绘制共用状态，`renderer.cpp` 应用打印布局并编码有界 GIF/PNG；`settings.cpp` 校验并保存设置。
- 蓝牙由 `platform/idf/ble_runtime` 统一管理。温湿度计使用需求槽0、像素屏使用槽1；任一模块仍有需求时保留主机。建立连接时暂停扫描，连接建立后恢复扫描。连接持有主机租约，失败和退出都先收尾再释放；最后一个需求消失后延迟释放主机。
- P4 通过本机 HCI 使用共享的远端控制器，蓝牙生命周期由平台统一管理。
- 设备密码不进入诊断输出，保存与读取使用配置加密接口。未知能力不作为硬件已支持的依据。
- `activity.h` 将打印机上报的当前阶段归为加热、回零、调平、清洁、耗材、校准及通用检查动画；未知准备阶段显示静止黄头。不按耗时推测动作，也不改变暂停、故障等状态的优先级。
- 第一层前百分比为黄色，第一层开始后为绿色；打印中换料不返回黄色。普通打印模型按层数堆叠，阶段结束后恢复用户选择的打印布局。
- 阶段数据仅用于外设联动和后台像素预览，控制屏不显示新增的阶段提示文字。新任务、首层转换与结束状态清除过期阶段，缺省字段遵循增量报告语义。
- `filament.h` 从当前喷嘴、AMS 或外置料盘选择颜色；换料时区分当前料和目标料。尖端为当前料色，圆心和打印头内部流动像素为进料色；未知颜色不使用备用色闪动，打印头保持白色、尖端为黄色；已识别的黑色映射为可见深灰。动态图使用独立调色板，不修改全局颜色表，使用独立64色调色板和有界增量GIF编码。

适用于兼容的 32×32 iDotMatrix 设备；其他协议或尺寸不在当前支持范围内。

打印中提供彩色打印机和进度视图两种布局。进度视图已完成段彩色向右慢跑，未完成段使用耗材色。待机温湿度默认关闭，启用后与时钟每10秒交替；无有效读数时保留内置时钟。
