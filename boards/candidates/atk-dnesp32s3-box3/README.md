# ATK-DNESP32S3 BOX3

实物测试状态：➖ 未实测。

适用厂家2.4英寸320×240屏幕组合：ST7789V2，4线SPI；CHSC5432电容触摸，I2C地址0x2E；AW9523BTQR控制电源、背光及触摸复位。不是BOX1/BOX2的I80接线。

16MB Flash、8MB PSRAM，ES8311与NS4150B输出。背光采用开关控制；红蓝双色灯不作为RGB状态灯。SD接口暂未启用。
